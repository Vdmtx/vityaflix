# ВитяФликс / Vityaflix

Videoteca pessoal com interface inspirada em serviços de streaming, hospedada no GitHub Pages e usando o Google Drive como origem dos vídeos.

## Estado atual

- Interface em azul escuro/ciano
- Logo `ВитяФликс` com subtítulo `Vityaflix`
- Busca local
- Seções por categoria
- Alguns links reais do Google Drive já associados
- Layout responsivo para desktop, smartphone e Android Box

## Próxima etapa

Trocar o catálogo fixo por leitura automática da pasta `filmes` do Google Drive, ignorando `.srt`, `.zip`, `.rar`, `.txt`, removendo duplicatas e priorizando arquivos em 720p.
